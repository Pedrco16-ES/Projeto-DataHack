# Dashboard previsto

O dashboard será implementado a partir da Etapa 6: panorama, P1 trajetória, P2 cursos e áreas, P3 rede/modalidade, P4 CPC, P5 licenciaturas, B1 oferta municipal e B2 financiamento.

Não há app.py executável nesta etapa. A interface administrativa será local e separada. O botão de atualização pública deverá apenas recarregar resultados aprovados. Filtros, exportações protegidas e fallback offline ainda estão pendentes.
